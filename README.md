# College Admission Form

## 📌 Project Description

This is a simple **College Admission Form** created using only **HTML**. The form allows students to enter their personal information, academic details, and upload required documents.

## ✨ Features

* Student Information Form
* Full Name Input
* Father's Name Input
* Mother's Name Input
* Date of Birth
* Gender Selection
* Email Input
* Phone Number Input
* Address Section
* Course Selection
* Previous Qualification
* Percentage / CGPA Input
* Photo Upload
* Marksheet Upload
* Submit Button
* Reset Button
* Navigation Links

## 🛠️ Technologies Used

* HTML5

## 📝 Form Sections

### 1. Student Information

The form collects:

* Full Name
* Father's Name
* Mother's Name
* Date of Birth
* Gender
* Email
* Phone Number
* Address

### 2. Academic Information

Students can provide:

* Selected Course
* Previous Qualification
* Percentage or CGPA

Available courses include:

* B.Tech CSE
* BCA
* BBA
* B.Sc
* BA

### 3. Documents

Students can upload:

* Profile Photo
* Marksheet

## 🚀 How to Run the Project

1. Download the project files.
2. Open the project folder.
3. Open the `index.html` file in a web browser.
4. Fill in the College Admission Form.
5. Click the **Submit** button.
